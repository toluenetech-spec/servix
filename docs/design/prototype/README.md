# Servix app — UI design prototype v1

Clickable HTML mock-up of the customer Android app, used to agree the look before the
Android agent implements it. Open `index.html` (any static server) — phone frame on desktop,
full-screen on a phone. Top strip switches screens; the bottom nav and cards are tappable.

Screens: Home (dashboard), Explore, Professional profile, Service detail, Booking sheet,
Bookings, Servix AI, Account. Brand tokens from `docs/ANDROID_DESIGN_PLAN.md`
(Deep Forest / Forest Green / Warm Ivory / Soft Sand / Coral; Inter; radii 16/24/12).

`img/*` are AI-generated placeholder portraits and a placeholder cover — design reference only,
never shipped in the app or the store listing.
