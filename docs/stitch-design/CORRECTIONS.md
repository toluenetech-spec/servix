# Servix Stitch designs — corrections and hand-off notes

**Status:** corrected, not yet implemented. Source of truth for the Android redesign is this folder:

| Folder | What it holds |
| --- | --- |
| `original/` | The 18 HTML files exactly as exported from Stitch (Google Drive folder "Servix UI UX design"). Never edited. |
| `corrected/` | 17 files produced by `tools/correct.py` from the originals (the superseded `s4_create_account.html` is dropped; `s4_create_account_corrected.html` becomes `s4_create_account.html`). Layout, components and motion are Stitch's; only theme, copy and a few elements changed. |
| `new/` | 14 screens Stitch did not deliver, generated by `tools/new_screens.py` with the same `<head>`/theme as the corrected files. |
| `assets/` | Two self-contained SVG placeholders that replace the Google-hosted AI images. |
| `tools/` | The two scripts. Re-running them is idempotent and asserts every edit. |
| `index.html` | Tap-through index of all 31 screens. |

Open `index.html` on a phone (any browser) — the pages load Tailwind and the Inter / Material Symbols fonts from the web, everything else is local.
